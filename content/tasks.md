# logiTask Tasks

Reference list of the tasks shown on the logiTask home page (`assets/task_home.png`).

logiTask lets you create a tailored set of standardized user testing tasks to evaluate and compare the effectiveness of any pointing or text entry device (mouse, touchpad, stylus, keyboard, ...).

Device legend: Mouse (red), Touch/Pointer (yellow), Keyboard (purple).

| # | Task | Description | Devices |
|---|------|-------------|---------|
| 1 | Point-and-Click (Fitts Task) | Test performance when doing point-and-click type actions. | Mouse, Touch/Pointer |
| 2 | Control (Steering Task) | Test fluidity of movement and overall control. | Mouse, Touch/Pointer |
| 3 | Precision (Drawing Task) | Test pixel-level precision of movements. | Mouse, Touch/Pointer |
| 4 | Typing | Test typing performance. | Keyboard |
| 5 | Vertical Scroll | Test vertical scrolling performance. | Mouse, Touch/Pointer |
| 6 | Multi-Directional Scroll | Test multidirectional scrolling and scroll wheel zooming. | Keyboard, Mouse, Touch/Pointer |
| 7 | Slider | (no description shown) | Mouse, Touch/Pointer |
| 8 | Drag-and-Drop | Test control and accuracy when moving objects. | Mouse, Touch/Pointer |
| 9 | Snap | (no description shown) | Mouse, Touch/Pointer |
| 10 | DIDOT | (no description shown) | Mouse, Touch/Pointer |
| 11 | Reaction Time | (no description shown) | Mouse |
| 12 | Clicks | (no description shown) | Mouse |
